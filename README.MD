## About This Project

This application is similar to other projects in my profile. The most similar one is **Inventario Escritorio**, which looks almost identical. The main difference is that this project is a **web application** built with **MariaDB** and **TypeScript**, while the other one is a **desktop application** built with **Ionic**, **Vue.js**, and **SQLite**.

This project was created mainly to practice and improve my development skills. I have also used **ChatGPT** and **GitHub Copilot** to help update dependencies, refactor legacy code, and assist with various development tasks.

The application is still a work in progress. Over time, I plan to improve the codebase, add new features, and continue refining the user experience.

## Getting Started

Run the following commands in separate terminals:

```bash
npm run watch:client
npm run dev
npm run build:css
```
